# 🎮 Chrono-Hackers

Un gioco in **Realtà Mista WebXR** dove stabilizzi anomalie temporali attraverso varchi VHS.

## 🌟 Caratteristiche

- ✅ **Realtà Mista** per Meta Quest 3 (con passthrough e hand tracking)
- ✅ **Modalità Desktop** con supporto completo per controller Xbox
- ✅ **Fallback Mouse/Tastiera** per massima compatibilità
- ✅ **Estetica VCR/VHS** con effetti glitch retrò
- ✅ **Zero installazioni** - gioca direttamente dal browser

## 🎯 Come Giocare

### Obiettivo
Afferra le **anomalie temporali** (cubi luminosi) e riportale al **Varco VHS** per stabilizzare la timeline.

### Controlli

#### 🥽 Su Meta Quest 3
1. Apri il **Browser Meta Quest**
2. Visita il link del gioco
3. Clicca su **"Enter VR"**
4. Usa le **mani** per afferrare le anomalie (pizzica con pollice e indice)
5. Riporta l'oggetto al portale luminoso

#### 🎮 Su PC con Controller Xbox
- **Stick Sinistro**: Movimento
- **Stick Destro**: Rotazione camera
- **Pulsante A** o **RT**: Afferra anomalia
- **Pulsante B**: Rilascia anomalia

#### 🖱️ Su PC con Mouse/Tastiera
- **W, A, S, D**: Movimento
- **Mouse**: Rotazione camera
- **Click Sinistro**: Afferra/Rilascia anomalia

## 🛠️ Tecnologie Utilizzate

- [Babylon.js](https://www.babylonjs.com/) - Motore 3D WebGL
- WebXR Device API - Realtà Mista/Virtuale
- Gamepad API - Supporto controller

## 📱 Compatibilità

- ✅ Meta Quest 2, 3, Pro
- ✅ Qualsiasi visore compatibile WebXR
- ✅ Browser desktop (Chrome, Edge, Firefox)
- ✅ Controller Xbox, PlayStation, generici

## 🚀 Sviluppo Locale

Se vuoi modificare il gioco:

```bash
# Clona il repository
git clone [URL_REPOSITORY]

# Apri la cartella
cd chrono-hackers-webxr

# Avvia un server locale (esempio con Python)
python3 -m http.server 8000

# Oppure con Node.js
npx http-server -p 8000
```

Poi visita `http://localhost:8000` nel browser.
