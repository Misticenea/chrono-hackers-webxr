# 🚀 Istruzioni per Abilitare GitHub Pages

Il repository è stato creato con successo su GitHub:
**https://github.com/Misticenea/chrono-hackers-webxr**

Per completare il deployment e ottenere il link HTTPS, segui questi semplici passaggi:

## Passaggi per Abilitare GitHub Pages

1. **Vai al repository su GitHub:**
   - Apri: https://github.com/Misticenea/chrono-hackers-webxr

2. **Accedi alle Impostazioni:**
   - Clicca sulla tab **"Settings"** (Impostazioni) in alto a destra

3. **Vai alla sezione Pages:**
   - Nel menu laterale sinistro, scorri verso il basso e clicca su **"Pages"**

4. **Configura la sorgente:**
   - Sotto "Build and deployment" → "Source"
   - Seleziona: **"Deploy from a branch"**
   - Branch: Seleziona **"gh-pages"**
   - Folder: Seleziona **"/ (root)"**
   - Clicca su **"Save"**

5. **Attendi il deployment:**
   - GitHub impiegherà 1-2 minuti per pubblicare il sito
   - Vedrai un messaggio verde con il link quando sarà pronto

## 🎮 Link del Gioco

Dopo aver completato i passaggi sopra, il tuo gioco sarà accessibile a:

**https://misticenea.github.io/chrono-hackers-webxr/**

## 📱 Come Giocare sul Quest 3

1. Apri il **Browser Meta Quest** sul tuo visore
2. Digita o incolla l'URL: `https://misticenea.github.io/chrono-hackers-webxr/`
3. Clicca sul pulsante **"Enter VR"** quando la pagina si carica
4. Goditi l'esperienza in Realtà Mista!

## 🖥️ Come Giocare su PC

1. Apri Chrome, Edge o Firefox
2. Visita: `https://misticenea.github.io/chrono-hackers-webxr/`
3. Usa mouse/tastiera o collega un controller Xbox
4. Clicca su **"⚙ IMPOSTAZIONI"** per regolare la grafica

## ⚙️ Impostazioni Grafiche Disponibili

- **Basso**: Per dispositivi meno potenti
- **Medio**: Bilanciamento tra qualità e performance
